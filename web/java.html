Ruby calling Java, in your browser

JRuby's Java integration, compiled to JavaScript with TeaVM. The Java classes of java-classes.txt (JDK basics, demo classes, parts of JBox2D and ZXing) are built into jruby.js, and Ruby uses them as on the JVM: java.util.ArrayList.new, blocks as Java interfaces, Java exceptions, Java calling back into Ruby. CRuby and ruby.wasm cannot do this. Ctrl+Enter runs the code. Plain Ruby REPL · Visual demo: JBox2D physics and ZXing QR codes on a canvas
