# java-classes.txt: the Java classes that Ruby code can use in the browser build (JRuby Java integration).
#
# TeaVM compiles ahead of time, so there is no class loading and no reflection unless it is declared at build
# time. For every class listed here the build
#   * makes it loadable by name from Ruby (java.util.ArrayList, Java::JavaUtil::ArrayList, java_import ...)
#     through a generated registry (scripts/gen-registry.sh -> org.jruby.gen.JavaClassRegistryImpl),
#   * emits TeaVM reflection metadata for its public constructors, methods and fields, and for those of all its
#     superclasses and superinterfaces (teavm-plugin/jrubyweb/teavm/JavaClassesPolicy.java),
#   * and, for an interface, generates the java.lang.reflect.Proxy class JRuby uses when Ruby implements it
#     (a block passed for the interface, Iface.impl { }, or a Ruby class doing `include Iface`).
#
# Format: one binary class name per line ('#' starts a comment). Optional words after the name restrict the
# class's own members to those names ("new" = its constructors); its supertypes stay unrestricted.
# Add a class: append a line, rebuild (./build.sh). Your own Java sources go under demo-src/ (any package).
# Every class costs code size (its public methods are compiled in).
# Not supported: java.time (not in TeaVM's class library), Ruby subclasses of Java classes (no bytecode generation).
